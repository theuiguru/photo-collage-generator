# Python Photo Collage Generator

A lightweight Python script using the [Pillow](https://python-pillow.org/) library to automatically combine all images in a folder into a clean, uniform grid collage (`.jpg`).

## Prerequisites

* Python 3 installed on your system.

## Installation & Setup

1. Clone or download this repository into a folder on your computer.
2. Place your photos inside a subfolder (e.g., a folder named `photos/`).
3. Open your terminal in the project folder and set up a virtual environment:
